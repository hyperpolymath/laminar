= Roadmap
:toc:
:sectnums:

This document outlines planned features and improvements for Laminar.
Last updated: 2025-12-17

== Current Phase: v0.1 (Foundation)

=== Completed
- [x] RSR (Rhodium Standard Repository) compliance foundation
- [x] Multi-platform CI/CD (GitHub, GitLab, Bitbucket)
- [x] SHA-pinned GitHub Actions for security
- [x] SPDX license headers on all files
- [x] OSSF Scorecard integration
- [x] CodeQL security scanning (when applicable)
- [x] STATE.scm, META.scm, ECOSYSTEM.scm documentation

=== In Progress
- [ ] Guix package definition refinement
- [ ] flake.nix for Nix users (fallback)
- [ ] Containerfile for container deployments

== Version 0.2 (Core Functionality)

=== Streaming Engine
- [ ] Implement primary cloud-to-cloud transfer features
- [ ] Rclone RC API integration
- [ ] Broadway pipeline for 4-lane processing (ghost/express/squeeze/refine)

=== Testing
- [ ] Add comprehensive ExUnit tests
- [ ] Property-based testing where applicable
- [ ] Integration tests for API boundaries
- [ ] Target: 70% test coverage

=== Documentation
- [ ] API documentation (ExDoc)
- [ ] Architecture decision records in META.scm
- [ ] User guides

== Version 0.5 (Feature Complete)

=== Multi-SA Parallel Transfer (TOC-Optimized)

- [ ] File routing decision engine
- [ ] Smart compression selection
- [ ] File type classification

=== CLI Polish
- [ ] Full command-line interface
- [ ] Transfer profiles
- [ ] Progress visualization
